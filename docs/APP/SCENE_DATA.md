# APP 场景数据与组件

场景编辑器支持在项目内上传 CSV 或 XLSX 数据集，并把当前步骤保存为带版本号的复用组件。数据集和组件版本创建后不可修改；需要调整时创建新版本。数据集与组件只对对应项目的成员和管理员可见。

CSV 使用 UTF-8 编码；XLSX 默认读取第一个工作表。单个文件上限 5 MiB、2,000 行和 100 列。执行时可选择单行，或最多 1,000 行顺序执行；每行拥有独立的执行记录，同一批次只占用一个设备租约。上传和配置不会触发设备操作，只有用户提交执行后才会开始。

标记为敏感的列以及名称明显表示密码、令牌或密钥的列，只允许使用 `secret://别名`，不要上传明文凭据。场景敏感变量也应使用相同格式，并在输入步骤中引用该变量。项目组件的敏感参数和输入步骤应引用场景变量，不应保存明文或直接保存密钥别名。

服务端通过 `APP_SCENE_SECRET_ALIASES_JSON` 配置受允许的别名与对应值，配置对象使用 `projects` 按项目 ID 分组；只有明确放在 `global` 中的别名才会向所有有项目权限的执行者共享。同名别名优先使用项目配置。该配置只应放在权限受限的服务端环境文件或密钥管理系统中，不要提交到代码仓库、放进测试数据或发送给前端。客户端只能引用已配置的别名，不能指定任意环境变量名。别名在执行进程内解析，解析后的值不会写入任务队列参数或执行记录。执行前会重新检查项目权限。

敏感文本使用受控的设备输入通道；当前支持可打印 ASCII 字符，不支持的字符会在输入前报错。若输入结果因设备超时无法确认，设备会进入维护模式，管理员确认设备状态并解除维护后才能继续使用。实际输入法、分辨率和控件行为仍应在获授权的设备上验证。

可复用组件可声明参数和必填项；步骤中以 `params.参数名` 引用组件参数。场景中保存的是项目、组件类型与版本的引用，执行时会重新检查项目权限并限制嵌套深度和展开数量。旧的全局自定义组件和已有内嵌步骤继续按原有方式执行。
